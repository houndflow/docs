# Contributing

Thanks for helping improve the Hound Flow documentation. This repository holds the public docs for the Hound Flow platform; the platform source lives in separate repositories.

## What belongs here

- Corrections and clarifications to existing docs
- New guides, examples, and tool walkthroughs
- Fixes to broken links, typos, and formatting

## How to contribute

1. Fork the repository and create a branch (`docs/your-change`).
2. Make your changes. Keep the tone clear, direct, and professional.
3. Verify links resolve and Markdown renders correctly.
4. Open a pull request describing what changed and why.

## Style guidelines

- Use plain, concise language. Prefer short sentences and active voice.
- Use fenced code blocks for commands, config, and example output.
- Reference tools by their canonical names (e.g. `hound_detect_rug_risk`).
- Keep examples Base-focused and avoid inventing data or endpoints not in the docs.
- Use relative links between docs (e.g. `[Configuration](docs/configuration.md)`).

## Reporting issues

Found something wrong or missing? Open an issue with the page, the problem, and a suggested fix if you have one.
